# 剧本写作指南

这条视频成立的核心不是 K 线画得好，是**把生平事件翻译成行情语言**。下面是可以直接套用的翻译表和编排规则。

## 一、事件 → 行情 翻译表

| 生平事件 | 行情说法 |
|---|---|
| 出生 | 挂牌、开盘、IPO、发行 |
| 出生地偏远/异域 | 境外上市、IPO 在境外 |
| 幼年求学 | 小阳线、慢慢爬坡 |
| 一举成名 | 一字涨停、直接封板 |
| 名门联姻、拜入师门 | 借壳上市、被并购 |
| 长期不得志 | 一字横盘、无人问津、成交量归零 |
| 隐居、守孝、赋闲 | 停牌 |
| 第一次被贬/被逐 | 高位减持、被踢出局 |
| 政治打击、下狱 | 跌停、退市风险警示 |
| 流放、发配 | ST、带帽、跌到地板 |
| 平反、起复、遇赦 | V 型反转、地天板、绝地反弹 |
| 创作高峰 | 逆势新高、走出独立行情 |
| 去世 | 退市、收盘 |
| 身后名声 | 长期上涨、涨了 N 百年 |

翻译的两条铁律：

1. **用行情词，不用评价词。** 写"他被 ST 了"，不写"他遭到了不公正的对待"。
2. **保留史实骨架。** 梗是壳，年份、事件、年龄必须真。观众里总有懂的人。

## 二、选事件

一条视频 14–18 章，等于 14–18 个镜头。选法：

- **必须有**：出生 / 成名 / 最高点 / 最低点 / 转折或平反 / 去世
- **优先选有反差的一对**：比如"入朝为翰林"和"贬儋州渡海"，落差越大曲线越好看
- **一章一件事**，不要把"贬黄州、写赤壁赋、号东坡"塞进一章
- 拿不准的年份宁可不写。**错一个年份，整条视频的可信度就没了**

典型骨架（可直接套到多数文人/政治家身上）：

```
封面 → 出生(低开) → 少年(慢涨) → 成名(涨停) → 仕途顺遂(续涨)
→ 第一次打击(暴跌) → 低谷(横盘/停牌) → 最高点(新高)
→ 第二次打击(崩盘) → 流放(跌停) → 遇赦/平反(V反) → 去世(退市) → 结论
```

## 三、股价曲线怎么设计

纵轴是自适应的，所以**不用担心数值大小，只关心形状**。经验值：全片从 5 涨到 50 左右，跨度够大即可。

- **开头低**：出生在 10 上下，给后面留空间
- **中段要有主峰**：人生最高点放在全片 60%–75% 的位置，观众的情绪峰值在这
- **必须有横盘段**：连续 6–8 秒几乎水平的曲线，是节奏的呼吸口。全片都在涨或跌会像心电图，很累
- **低谷要"探底回升"**：跌到最低后加一小段横向或微升，别让它一路向下到黑屏
- **结尾不要归零**：去世时价格应停在中等区位（如 24），因为"退市"是终止交易，不是资产归零
- **章内形状**：一章 5 秒 ≈ 3.5 根 K 线。想要"垂直拉升"，让 0→1 的价格跨度大且集中在中段；想要"阴跌"，用 3–4 个缓降关键帧
- **关键帧要够密**：涨幅或跌幅超过 3 个单位时，至少给 5–6 个关键帧。只给 2 个（起点+终点）会画出一根**贯穿全屏的柱子**，一眼假。宁可多写两个点：

  ```json
  "price": [[0,11.6],[0.18,10.6],[0.38,9.2],[0.56,8.0],[0.78,6.9],[1,6.0]]
  ```

- **开头别写得太凶**：前 20 秒纵轴范围窄（往往只有 6–14 这么几个单位），同样 1.3 个单位的涨跌会占掉画面四分之一高，K 线会显得又粗又笨。开头几章的波动幅度控制在 2–3 个单位内

## 四、标题怎么写

每章 1–2 行，每行 ≤ 12 字。三种有效句式：

1. **数字 + 事件 + 行情词**
   `42岁，朝廷点了名，` / `直接{一字涨停}。`
2. **先陈述，再翻译**
   `27岁入赘相门，` / `这波叫{借壳上市}。`
3. **短句转折**
   `他没跑，` / `满仓押了{永王}。`

语气：**冷静、略带促狭、不煽情**。像一个人在旁边小声解说，不像语文老师在总结中心思想。

反面例子：

- ❌ `他的一生充满了坎坷与磨难` —— 评价句，没有信息量
- ❌ `苏轼，字子瞻，号东坡居士，眉州眉山人` —— 百科条目，不是解说
- ✅ `21岁进京赶考，/ 主考官说：{我要避路}。`

## 五、红字

每章只标 1 处，标在**这句的落点**上——通常是那个行情词或那句金句。

判断标准：如果把这四个字单独拿出来能当标题，就标红。

## 六、标注（`ann`）

图上小字，1–2 个/章，作用是给曲线上的拐点"钉"一个史实标签。

- 文字控制在 4–6 字：`乌台诗案`、`贬黄州`、`白帝城遇赦`
- 位置：上升段用 `above`，下跌段用 `below`
- 进度：钉在**那一根 K 线**上，不是章节开头
- 别每章都加。均匀分布在关键拐点，一章 0–2 个

## 七、脚注（`cite`）

放在成交量下方的一行小字，12px 浅灰。这是全片最"值钱"的细节，优先放：

- 当事人自己的诗句（首选）
- 史书原文
- 极简的事实补充（如"黄州团练副使，本州安置，不得签书公事"）

长度控制在一行内（≤ 24 字）。

## 八、收尾公式

最后两章固定套路：

```
第 N-1 章：{年龄}岁，{去世方式}。{姓名}，{退市}。
第 N 章（end）：他的一生，收盘在{年龄}岁。
            可他的{诗/词/思想}，{涨了 N 百年}。
```

"涨了 N 百年" 的 N 用当下的年份减去世年份，取整到"百"。这是全片唯一的抒情点，前面越克制，这里越有力。

## 九、常见问题

| 症状 | 原因 | 改法 |
|---|---|---|
| 看着像心电图 | 每章都在大涨大跌 | 插入 2 个 `calm` 横盘章 |
| 情绪起不来 | 最高点太早或太平 | 把主峰移到 60% 之后，并加大与前章的落差 |
| 标题读不完 | 单行超 12 字 | 拆成两行，或删修饰语 |
| 画面很空 | 章节太少、价格波动小 | 加到 16 章以上，把幅度拉到 5→50 |
| 数字和曲线对不上 | 相邻章节价格没接上 | 后一章 `price[0][1]` 改成前一章末值 |
| 有一根特别长的柱子 | 陡段只给了 2 个价格关键帧 | 拆成 5–6 个关键帧，把跌幅摊到 3–4 根 K 线上 |
| 配乐和画面不搭 | `tone` 全是默认值 | 按情绪表逐章设置，尤其是 `dark` 和 `recover` |
