# 剧本 JSON 字段说明

顶层两个字段：`person`（姓名，显示在左下角）与 `chapters`（章节数组，按顺序拼接时间轴）。

```json
{
  "person": "苏轼",
  "chapters": [ { ... }, { ... } ]
}
```

## 章节字段

| 字段 | 必填 | 类型 | 说明 |
|---|---|---|---|
| `dur` | ✓ | 秒 | 本章时长。全部相加即视频总长，建议 4–7 秒/章 |
| `lines` | ✓ | 字符串数组 | 标题，1–2 行最佳，最多 3 行 |
| `price` | ✓ | `[[进度, 价格], ...]` | 本章股价走势关键帧，进度 0–1 |
| `right` | | 字符串数组 | 右上角信息，0–3 行。第一行用深色，其余浅色 |
| `cite` | | 字符串 | 成交量下方的浅灰小字，放诗文出处/史书原文 |
| `tone` | | 枚举 | 配乐情绪，见下表。默认 `calm` |
| `ann` | | `[[文字, 位置, 进度], ...]` | 图上标注。位置取 `above`/`below` |
| `flash` | | `"red"`/`"green"`/`null` | 整屏晕染，用于暴涨/崩盘的情绪加强 |
| `stamp` | | `[文字, 进度]` | 深色印章，如 `["跌停", 0.7]`，进度为章内位置 0–1 |
| `end` | | 布尔 | 标记收尾章，印章自动挪到左侧空位 |

### `lines` 的红字标记

用花括号包住要染红的词，每行最多一处：

```json
"lines": ["42岁，朝廷点了名，", "直接{一字涨停}。"]
```

红字数量克制在每章 1 个——它承担"金句落点"的作用，多了就不值钱了。

### `price` 写法

```json
"price": [[0, 30.2], [0.42, 34.0], [0.67, 44.0], [1, 50.0]]
```

- 数组按进度升序，引擎用 smoothstep 插值，天然带缓动
- **价格的绝对值不重要**（纵轴自适应），重要的是**形状**：陡峭=剧烈，平缓=横盘
- 章末若不写 `1`，引擎自动用最后一个值补齐
- 下一章的第一个值应等于本章最后一个值，否则会形成"跳空缺口"——有时正好用来表现"一夜之间"

### `tone` 情绪对照

| 值 | 用途 | 音乐表现 |
|---|---|---|
| `calm` | 平淡岁月、早年 | 弱节奏、钢琴稀疏 |
| `rise` | 上升期 | 中速节拍进场 |
| `peak` | 人生最高点 | 全配器，鼓点最重 |
| `fall` | 失势、外放 | 节奏退后半步 |
| `crash` | 灾祸、下狱 | 低沉，垫子加厚 |
| `dark` | 流放、谷底 | 几乎只剩长音与零星琴音 |
| `recover` | 平反、遇赦 | 全配器 + 上行分解和弦 |
| `end` | 去世、收尾 | 收束、留白 |

## 最小可跑例子

```json
{
  "person": "某人",
  "chapters": [
    {"dur": 4.0, "lines": ["把某人的一生，", "画成一只{股票}。"], "price": [[0, 12], [1, 11.5]], "tone": "calm"},
    {"dur": 5.0, "lines": ["他这只股，", "一开盘就{破发}。"], "right": ["1900年 · 1岁", "持仓 无"], "cite": "某书某卷", "price": [[0, 11.5], [1, 8]], "tone": "calm", "ann": [["出生地", "below", 0.5]]},
    {"dur": 5.0, "lines": ["三十岁，他{改变了行业}。"], "right": ["1929年 · 30岁", "持仓 事业"], "price": [[0, 8], [1, 40]], "tone": "peak", "flash": "red", "ann": [["转折点", "above", 0.6]]},
    {"dur": 4.5, "end": true, "lines": ["他的一生，收盘在八十岁。", "可他的东西，{还在涨}。"], "right": ["1980年 · 80岁", "持仓 手稿", "退市"], "price": [[0, 40], [1, 39]], "tone": "end", "stamp": ["退市", 0.5]}
  ]
}
```

## 校验

`render.py` 会自动检查并打印 `[warn]`：章节过短、标题超 3 行、相邻章节股价跳变 >25%。看到 warn 就回去改，不要忽略。
